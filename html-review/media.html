<video> Tag

Definition

The <video> tag displays a video on a web page.

Attributes

Attribute Role
controls Displays video controls.
width Defines the video width.
autoplay Starts the video automatically.

Example (code)

<video controls width="400">
    <source src="images/video.mp4" type="video/mp4">
</video>

Example (result)

<audio> Tag

Definition

The <audio> tag adds sound or music to a web page.

Attributes

Attribute Role
controls Displays audio controls.
autoplay Starts the audio automatically.
loop Repeats the audio.

Example (code)

<audio controls>
    <source src="images/audio.mp3" type="audio/mpeg">
</audio>

Example (result)

<source> Tag

Definition

The <source> tag specifies a media file for audio or video.

Attributes

Attribute Role
src Specifies the media file location.
type Specifies the media type.

Example (code)

<source src="video.mp4" type="video/mp4">

Example (result)

The source file is used by the video or audio element.
