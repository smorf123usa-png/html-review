<form> Tag

Definition

The <form> tag creates a form for collecting user information.

Attributes

Attribute Role
action Specifies where form data is sent.
method Defines how the form data is sent.

Example (code)

<form action="/submit" method="post">
    <input type="text">
</form>

Example (result)

<input> Tag

Definition

The <input> tag creates an input field for user data.

Attributes

Attribute Role
type Defines the type of input.
name Defines the name of the input.
placeholder Shows temporary text inside the input.

Example (code)

<input type="text" placeholder="Your name">

Example (result)

<button> Tag

Definition

The <button> tag creates a clickable button.

Attributes

Attribute Role
type Defines the button type.
disabled Disables the button.

Example (code)

<button type="submit">Submit</button>
