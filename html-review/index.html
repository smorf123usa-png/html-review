HTML Page Structure

This page introduces the basic structure of an HTML document.

<html> Tag

Definition

The <html> tag is the root element of an HTML document. All other HTML elements are placed inside it.

Attributes

Attribute Role
lang Defines the language of the document.
id Gives the element a unique identifier.

Example (code)

<html lang="en">
    Page content
</html>

Example (result)

The whole web page is contained inside the HTML element.

<head> Tag

Definition

The <head> tag contains information about the document that is not normally displayed as page content.

Attributes

Attribute Role
id Gives the head element a unique identifier.
class Assigns the element to a CSS class.

Example (code)

<head>
    <title>My Website</title>
</head>

Example (result)

The page title appears in the browser tab.

<body> Tag

Definition

The <body> tag contains the visible content of an HTML page.

Attributes

Attribute Role
id Gives the body a unique identifier.
class Assigns the body to a CSS class.

Example (code)

<body>
    <h1>Hello World</h1>
    <p>This is my page.</p>
</body>

Example (result)

Hello World

This is my page.
