<a> Tag

Definition

The <a> tag creates a hyperlink to another page or website.

Attributes

Attribute Role
href Specifies the link destination.
target Specifies where to open the link.

Example (code)

<a href="https://www.google.com">Google</a>

Example (result)

Google

<img> Tag

Definition

The <img> tag displays an image on a web page.

Attributes

Attribute Role
src Specifies the image location.
alt Provides alternative text for the image.
width Defines the image width.

Example (code)

<img src="images/picture.jpg" alt="A picture">
