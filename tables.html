<table> Tag

Definition

The <table> tag creates a table for displaying data.

Attributes

Attribute Role
id Gives the table a unique identifier.
class Assigns the table to a CSS class.

Example (code)

<table>
    <tr>
        <td>HTML</td>
    </tr>
</table>

Example (result)

HTML

<tr> Tag

Definition

The <tr> tag defines a row in an HTML table.

Attributes

Attribute Role
id Gives the row a unique identifier.
class Assigns the row to a CSS class.

Example (code)

<tr>
    <td>John</td>
</tr>

Example (result)

John

<th> Tag

Definition

The <th> tag defines a header cell in a table.

Attributes

Attribute Role
colspan Specifies how many columns the cell spans.
rowspan Specifies how many rows the cell spans.

Example (code)

<th>Name</th>

Example (result)

Name
