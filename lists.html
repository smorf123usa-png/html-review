<ul> Tag

Definition

The <ul> tag creates an unordered list.

Attributes

Attribute Role
id Gives the list a unique identifier.
class Assigns the list to a CSS class.

Example (code)

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

Example (result)

  • HTML
  • CSS

<ol> Tag

Definition

The <ol> tag creates an ordered list.

Attributes

Attribute Role
start Defines the starting number.
type Defines the numbering style.

Example (code)

<ol>
    <li>First</li>
    <li>Second</li>
</ol>

Example (result)

  1. First
  2. Second

<li> Tag

Definition

The <li> tag defines an item inside a list.

Attributes

Attribute Role
value Defines the number of an ordered list item.

Example (code)

<li>HTML</li>
