<header> Tag

Definition

The <header> tag defines the introductory part of a page or section.

Attributes

Attribute Role
id Gives the header a unique identifier.
class Assigns the header to a CSS class.

Example (code)

<header>
    <h1>My Website</h1>
</header>

Example (result)

My Website

<section> Tag

Definition

The <section> tag defines a section of related content.

Attributes

Attribute Role
id Gives the section a unique identifier.
class Assigns the section to a CSS class.

Example (code)

<section>
    <h2>About Us</h2>
    <p>Information about our website.</p>
</section>

Example (result)

About Us

Information about our website.

<article> Tag

Definition

The <article> tag defines independent and self-contained content.

Attributes

Attribute Role
id Gives the article a unique identifier.
class Assigns the article to a CSS class.

Example (code)

<article>
    <h2>News</h2>
    <p>This is a news article.</p>
</article>

Example (result)

News

This is a news article.
